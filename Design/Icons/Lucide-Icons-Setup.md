# تعليمات تحميل وإعداد أيقونات Lucide لمنصة ركيزة

## المكتبة المعتمدة

استخدم **Lucide** لأيقونات واجهات ركيزة، وحافظ على نفس الأسلوب في جميع الشاشات.

- [تصفح الأيقونات في All SVG Icons](https://allsvgicons.com/pack/lucide/)
- [الموقع الرسمي للمكتبة](https://lucide.dev/)

## 1. تحميل الأيقونات للتصميم

1. افتح صفحة Lucide في الرابط أعلاه.
2. ابحث عن الأيقونة باسمها الإنجليزي، مثل `house` أو `wallet`.
3. اختر الأيقونة وافتح تفاصيلها.
4. استخدم صيغة **SVG** للحفاظ على قابلية تعديل الأشكال.
5. إذا نسخت كود SVG بدل تنزيل ملف، احفظ الكود كاملًا في ملف نصي بامتداد `.svg` وترميز UTF-8؛ مثل `house.svg`.
6. اجمع الملفات داخل مجلد المشروع المقترح `design/icons/lucide/`.

هذه ملفات متجهية وليست خطوطًا؛ لا تُثبّت داخل مجلد Fonts. لا تحتاج إلى ربط MCP لاستخدام ملفات SVG يدويًا.

## 2. استخدامها في Adobe Illustrator

1. اختر **File > Open** وافتح ملف الأيقونة بصيغة SVG.
2. انسخ الأيقونة إلى ملف واجهة ركيزة.
3. عدّل حجمها مع الحفاظ على نسبة العرض إلى الارتفاع.
4. عدّل لون **Stroke** وسُمكه ليناسبا بقية الأيقونات.
5. احتفظ بمسارات الأيقونة داخل مجموعة مستقلة، وسمّها حسب وظيفتها.

حافظ على الأيقونة كعنصر متجهي. النصوص المجاورة لها تبقى نصوصًا حية بخط ثمانية واتجاه RTL، ولا تُحوّل إلى Outlines.

## 3. استخدامها في Figma

1. اسحب ملف SVG إلى صفحة التصميم.
2. راجع حجمه ولون الخط وسُمكه بعد الاستيراد.
3. استخدم مكوّنًا قابلًا لإعادة الاستخدام للأيقونات المتكررة.
4. سمِّ المكونات بوضوح، مثل `Icon/House` و`Icon/Wallet`.

## 4. تثبيتها في مشروع React — للمطور

نفّذ الأمر التالي داخل مجلد المشروع:

```bash
npm install lucide-react
```

مثال:

```jsx
import { House, Wallet, Bell } from 'lucide-react';

export default function NavigationIcons() {
  return (
    <div dir="rtl" style={{ display: 'flex', gap: 16, color: '#FFFFFF' }}>
      <House size={24} strokeWidth={1.75} aria-hidden="true" />
      <Wallet size={24} strokeWidth={1.75} aria-hidden="true" />
      <Bell size={24} strokeWidth={1.75} aria-hidden="true" />
    </div>
  );
}
```

هذا مثال لعرض الأيقونات فقط. إذا استُخدمت أيقونة داخل زر دون نص ظاهر، أضف للزر اسمًا واضحًا لقارئات الشاشة، مثل `aria-label="الإشعارات"`.

استورد الأيقونات المطلوبة فقط، ولا تفترض أن حزمة React مناسبة لتطبيق iOS الأصلي؛ اختر تكامل المكتبة المناسب لتقنية التطبيق.

مرجع التثبيت: [توثيق Lucide React الرسمي](https://lucide.dev/guide/packages/lucide-react).

## 5. تنسيق أيقونات ركيزة

هذه قواعد التصميم المقترحة للمشروع:

| الخاصية | القيمة |
| --- | --- |
| الحجم المعتاد | 24 × 24 بكسل |
| الحجم داخل العناصر الصغيرة | 20 × 20 بكسل |
| سُمك الخط | 1.75 بكسل عند حجم 24 بكسل |
| اللون الأساسي على الخلفيات الداكنة | `#FFFFFF` |
| لون الإبراز | `#90AAFC` |
| خلفية حاوية الأيقونة | `#454E69` |
| الأسلوب | خطي، بنهايات مستديرة |

- لا تخلط أيقونات Lucide مع مكتبات مختلفة في الشاشة نفسها.
- لا تمدد الأيقونات أو تغيّر نسبها.
- راجع اتجاه الأسهم بحسب وظيفتها في واجهة RTL؛ لا تعكس جميع الأيقونات تلقائيًا.
- حافظ على حجم وسُمك موحدين للأيقونات المتجاورة.
- الشعار الأصلي لركيزة مستقل عن مكتبة الأيقونات ولا يُستبدل بأيقونة مبنى.

## 6. أسماء البحث للأيقونات المطلوبة

| الاستخدام | اسم البحث |
| --- | --- |
| الرئيسية | `house` |
| الإشعارات | `bell` |
| الميزانية | `wallet` |
| المصروفات | `coins` |
| الدفعة القادمة | `calendar-days` |
| قائمة الفحص | `clipboard-check` |
| إضافة مصروف | `circle-plus` |
| تسجيل شراء | `shopping-cart` |
| المراحل | `layers` |
| المواد | `box` |
| المزيد | `ellipsis` |

قد تختلف أسماء الاستيراد البرمجية عن أسماء ملفات SVG؛ تحقّق من اسم المكوّن في إصدار الحزمة المستخدم.

## 7. مراجعة قبل التسليم

- ملفات الأيقونات متجهية وواضحة عند التكبير.
- أسماء الملفات والمكونات تعبّر عن وظيفتها.
- الأحجام والألوان وسُمك الخط متسقة.
- النصوص العربية مستقلة عن الأيقونات، قابلة للتحرير، واتجاهها صحيح.
- احتفظ بإشعارات الحقوق وملف الترخيص المرفق بإصدار المكتبة عند توزيع أصوله.

> هذا الملف تعليمات للإعداد والاستخدام، ولا يعني أن مكتبة برمجية ثُبّتت أو اتصال MCP أُضيف إلى جهازك.
